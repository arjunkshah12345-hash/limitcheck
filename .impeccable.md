# Design Context

## Users

People operating coding agents—Claude Code, Codex, Cursor, OpenCode, CrocBot, and similar harnesses—who need a fast answer about how much provider quota remains before deciding how much work to delegate.

## Brand Personality

Calm, clever, and scrappy. The interface should reduce uncertainty without adding another dashboard to babysit. It should feel like a useful note from a technically-minded friend: direct, warm, and a little hand-drawn.

## Aesthetic Direction

Light-first editorial developer tooling, inspired by the warm paper, Fraunces/Caveat typography, marker-orange accents, and hand-drawn diagrams of [social-sdk.dev](https://social-sdk.dev/). Use that reference as a visual cue, not a copy: Limitcheck gets its own gauge / runway motif and a restrained code-terminal layer. Support a dark theme as a practical option.

## Design Principles

1. One glance should answer “how much runway is left?”
2. Make the protocol boring and portable: shell in, JSON out.
3. Use illustrative marks only when they clarify the concept.
4. Keep the surface small enough to trust.
5. Treat rate limits as planning data, not an anxiety-inducing alarm.
