# Limitcheck assets

These are the small, reusable brand files for the project:

- [`limitcheck-lockup.svg`](limitcheck-lockup.svg) — icon + wordmark for docs, slides, and launch materials.
- [`../public/mark.svg`](../public/mark.svg) — favicon-sized geometric runway gauge.
- [`../public/og.svg`](../public/og.svg) — social preview artwork used by the Vercel site.

The visual language is warm off-white, dark ink, a restrained orange signal, and a geometric runway gauge. Keep new assets precise and legible at small sizes.
